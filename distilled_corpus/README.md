# Distilled Corpus v2

A synthetic, verified distillation corpus for pretraining / post-training a small
language model. Generated by **distilling strong teacher models** on a structured
curriculum of concepts across 8 domains, then verifying, deduplicating, and
finalizing each document.

## Dataset summary

| Metric | Value |
|--------|-------|
| Documents | 1,252 |
| Estimated tokens | ~3.07M (chars / 4.0) |
| Total characters | 12,284,526 |
| Language | English (100%) |
| Verification | 100% (heuristic + LLM verifier) |
| Synthetic | 100% |

## Contents

| File | Description |
|------|-------------|
| `final/final_corpus.jsonl` | **Training-ready**: one JSON object per line (`id`, `text`, `metadata`, `provenance`) |
| `final/dataset_statistics.json` | Full stats: domains, difficulty, task types, teachers, context lengths |
| `final/provenance.jsonl` | Provenance trail (teacher model, elapsed, seed) per document |
| `final/quality_report.json` | Quality scoring summary |
| `deduplicated/deduplicated.jsonl` | Post-dedup records (exact + near-dup + semantic) |
| `verified/verified.jsonl` | All KEEP/REVIEW docs after LLM verification |
| `rejected/rejected.jsonl` | Docs rejected by verifier (not in final) |
| `raw/` | Raw teacher outputs (per-shard) |
| `metadata/` | Pipeline state (resumable) |

## Domains & difficulty

8 domains (technology, general_knowledge, mathematics, engineering, biology,
physics, chemistry, earth_space) × 6 difficulty levels (1=easy → 6=hard), across
9 task types (educational_explanation, encyclopedia_article, worked_example,
proof_or_derivation, qa_problem_solving, comparison, long_synthesis,
code_with_explanation, reasoning_example).

Context lengths: 256 → 32,768 tokens (longest docs are 16K/32K syntheses).

## Regeneration

The full pipeline lives in `distill_pipeline/`:

```bash
# 1. Plan curriculum + generate prompts
python distill_pipeline/generate.py
# 2. Generate docs (teacher runner — OpenRouter or NVIDIA)
NVIDIA_API_KEY=... python distill_pipeline/nvidia_runner.py
# 3. Verify (LLM verifier + heuristics + code execution)
LLM_API_BASE=... LLM_API_KEY=... python distill_pipeline/verify.py
# 4. Dedup + finalize
python distill_pipeline/dedup.py
python distill_pipeline/finalize.py
```
